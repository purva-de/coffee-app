# Coffee Co. - Fuel Your Day ☕

An artisanal, mobile-first coffee web application featuring interactive video reels, custom roast selections, an interactive barista brew calculator, dynamic shopping bag with promo codes, and full theme switching.

![Coffee Co. Banner](assets/coffee_craft.jpg)

## 🌟 Features

- **Embedded Video Showcase**: 9:16 vertical video reel seamlessly showcasing small-batch roasting, rocket fuel grind, and extraction.
- **Dark Roast & Light Cream Themes**: Accessible CSS variables design system with instant theme toggling.
- **8px Grid System**: Strict 8px spacing tokens throughout all UI components.
- **Accessible & Semantic HTML5**: Full ARIA support, landmark elements, structured JSON-LD schema, and `prefers-reduced-motion` compliance.
- **Signature Roasts Catalog**: High-resolution imagery for Midnight Velvet Dark Roast, Golden Dawn Medium Roast, Rocket Fuel Espresso, and Nitro Silk Cold Brew.
- **Barista Brew Calculator**: Dynamic ratio calculator and bloom stopwatch for Pour Over, French Press, Espresso, and Cold Brew.
- **Interactive Shopping Bag**: Real-time quantity adjustments, free shipping progress bar ($35 threshold), and promo discount engine (`FUEL10`).

## 🚀 Getting Started

To run locally:
```bash
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000) in any browser.
